## Sobre mí

Soy estudiante de informática y siempre me ha interesado cómo la tecnología se convierte en soluciones concretas: sistemas web, modelado de datos y procesos que se resuelven solos.

Aprendo construyendo. Empecé con ejercicios pequeños —CRUD, métodos numéricos, estructuras de datos— y a medida que avanzaba en los cursos me animé a hacer aplicaciones completas, con base de datos, autenticación y despliegue.

Hoy trabajo en proyectos con **Next.js** y **TypeScript**, y también en **Django y Python**, aplicando lo que estudio en métodos numéricos e investigación de operaciones.

### En qué me concentro

- **Desarrollo de software** — aplicaciones web completas, desde la interfaz hasta la base de datos.
- **Desarrollo web** — React, Next.js y diseño de APIs REST.
- **Bases de datos** — modelado relacional, SQL y uso de ORM.
- **Automatización** — scripts en Python, generación de reportes y procesamiento de datos.
- **Computación numérica** — métodos numéricos, álgebra lineal y visualización de resultados.
- **Autenticación y control de acceso** — sesiones, tokens, cifrado de contraseñas y roles.

## Proyectos destacados

### [Formulario de inscripción deportiva](https://github.com/fgonzalezpa/formulario-inscripcion-deportiva)

Web para gestionar el registro de equipos y participantes en actividades deportivas universitarias de la Facultad de Informática, Electrónica y Comunicación (FIEC).

Los datos se validan en el servidor y la base de datos impone reglas que impiden errores: una cédula no se repite, una persona no puede estar en dos equipos de la misma disciplina y un nombre de equipo no se duplica dentro de una disciplina. Incluye un panel de administración protegido por contraseña para consultar lo inscrito.

**Tecnologías:** Next.js, React, TypeScript, Tailwind CSS, PostgreSQL y Docker.
**Estado:** en desarrollo.

### [CRM interno](https://github.com/fgonzalezpa/crm-interno)

Sistema web interno para llevar el registro de clientes de un negocio: alta, edición, búsqueda, estadísticas y un historial de los cambios de cada cliente.

El acceso se controla por usuario y rol, las contraseñas se guardan cifradas y a los trabajadores se les incorpora mediante un código de invitación de un solo uso, con fecha de vencimiento.

**Tecnologías:** Next.js, React, TypeScript, Prisma, SQLite, Auth.js, Zod y Tailwind CSS.
**Estado:** en desarrollo.

### [Método Simplex](https://github.com/fgonzalezpa/Simplex)

Aplicación web para resolver problemas de programación lineal, maximizando o minimizando una función objetivo sujeta a restricciones.

Muestra el método paso a paso: tabla inicial, iteraciones, tabla final y gráfica de la región factible. Cada problema se guarda en el historial del usuario, se puede exportar a PDF e incluye una explicación del procedimiento generada con OpenAI. También expone una API REST documentada.

**Tecnologías:** Django, Django REST Framework, NumPy, Matplotlib, SymPy, WeasyPrint y OpenAI.
**Estado:** proyecto académico en desarrollo.

### [Método de transporte: Esquina Noroeste y Costo Mínimo](https://github.com/fgonzalezpa/CostoMinimo)

Dos versiones del mismo problema de transporte: decidir cómo enviar mercancía desde varios orígenes hacia varios destinos minimizando el costo total.

Se ingresa una matriz de costos junto con la oferta y la demanda de cada punto. La aplicación balancea el problema cuando no cuadran los totales y muestra el desglose del costo por ruta. Una de las versiones dibuja además la red de transporte y permite guardar comentarios del docente.

**Tecnologías:** Django, NumPy, NetworkX, Pandas y Matplotlib.
**Estado:** proyecto académico.

### [Método de Bairstow](https://github.com/fgonzalezpa/MethodBairstow)

Aplicación web para encontrar las raíces de un polinomio usando el método de Bairstow, que calcula las raíces cuadradas complejas de forma iterativa.

Guarda cada iteración y la gráfica de convergencia de cada problema, y requiere iniciar sesión para consultar el historial.

**Tecnologías:** Django, Django REST Framework, NumPy, SymPy y Matplotlib.
**Estado:** proyecto académico.

### [Framework Next](https://github.com/fgonzalezpa/framework-next)

Proyecto de práctica con Next.js: una plataforma temática con personajes, comunidades, temporadas y villanos.

Lo interesante aquí es el sistema de autenticación: registro, inicio de sesión y recuperación de contraseña, con las rutas protegidas desde el middleware y las contraseñas cifradas con bcrypt.

**Tecnologías:** Next.js, React, TypeScript, Tailwind CSS, jsonwebtoken y bcrypt.
**Estado:** proyecto de práctica.
